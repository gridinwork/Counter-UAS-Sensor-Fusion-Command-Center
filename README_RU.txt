СИСТЕМА ДЕТЕКТИРОВАНИЯ ДРОНОВ / DRONE DETECTION SYSTEM

Запуск / Start: install.bat (один раз / once), затем / then start.bat.
Язык интерфейса переключается кнопкой в правом верхнем углу (Русский / English).
Настройки сохраняются в config.json рядом с программой.

Данные принимаются только от реальных подключений (вкладка «Сенсоры / подключения»):
  Радар, 4 сенсорных поста, внешняя система (статус) —
    MAVLink 2 по UART (COM-порт) или UDP: HEARTBEAT, GLOBAL_POSITION_INT (радар → цели)
    JSON-строки по UART / UDP / TCP-клиент
  Pan/Tilt платформа — MAVLink (только статус связи)
  RGB-камера — RTSP, видео на вкладке «Камера»
Без подключённых источников целей нет.

Формат JSON (одно сообщение на строку, UDP — одна датаграмма; допускается массив):
  {"id":"T1","lat":47.01,"lon":28.86,"alt":120,"speed":18,"heading":45,
   "radar":true,"remote_id":"ABC123","rf24":true,"rf58":true,"acoustic":true,"cv":true,
   "class":"UAV","confidence":85}
Обязателен только "id". Сообщения с одним id от разных источников объединяются в одну цель.
Если "confidence" не задан, достоверность считается по подтверждающим источникам
(радар 30, зрение 30, акустика 15, 5,8 ГГц 10, Remote ID 10, 2,4 ГГц 5).
Скорость и курс вычисляются по смещению, если не переданы.
Белый список Remote ID задаётся в настройках: цель с ID из списка — «своя».
Внешняя станция реагирования получает отчёты {"type":"track_report",...} раз в секунду (UDP: на указанный адрес, ответы принимаются) и присылает статус {"status":"..."}. Программа ею не управляет.

Карта: OpenStreetMap/Leaflet, требуется интернет.

English: the program shows only data received from real connections
(MAVLink 2 over UART/UDP, JSON lines over UART/UDP/TCP, RTSP video). See the JSON format above.
